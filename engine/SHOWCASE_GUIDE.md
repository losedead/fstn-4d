# 向别人推荐 FSTN-4D 的展示指南

> 核心策略：**不要讲功能，要讲差异**。让对方亲眼看到"没有它 vs 有它，同样一句话差多少"。
> 全程 3 分钟，1 条命令，4 句话。

---

## 开场（30 秒）— 一句话定位

> "现在的 AI Agent 都有记忆，但记忆是**没有情绪的**。这个引擎给 Agent 装上'情感记忆'——它会感知你的状态、记住带情绪的经历、并让情绪反过来影响它怎么回应你。"

**停顿一下，让对方有概念。**

## 核心展示（90 秒）— 一条命令

```bash
cd ~/Desktop/fstn_enhancement/engine && python showcase.py
```

跑完 4 句对比后，指着屏幕讲：

### 第 1 句：『好热啊，帮我把空调打开』
- 普通 LLM：`好的，我帮您打开空调。`（机械执行）
- FSTN-4D：先显示**感知追踪** `thermal_comfort=-0.7, sweating`，再给直接行为 `heat → cooling (W_p=0.85)`，最后回复"别对着风口吹，容易着凉"
- **一句话点评**："它不只是执行指令，它'感觉到'你在热。"

### 第 2 句：『今天工作被批评了，好难过』
- 普通 LLM：`一切都会好起来的。`（典型的无效安慰——否认了对方的难过）
- FSTN-4D：检测到 `sadness 0.82`，回复"不用急着振作，我陪着你"
- **一句话点评**："它会顺着你的情绪，而不是跳过你的情绪。"

### 第 3 句：『还没吃饭，饿死了，而且今天工作特别烦』
- 普通 LLM：`好的，我帮您找点吃的。`
- FSTN-4D：识别**饿→怒耦合**（anger 0.82 + 饥饿 0.8），回复"又饿又烦最容易上火——先别做决定"
- **一句话点评**："它知道'饿和烦会互相放大'——这是普通人会懂、但普通 AI 不会算的事。"

### 第 4 句：『晚上听什么音乐好？』
- 普通 LLM：`好的，我推荐一些爵士乐给你。`（每次都是新的，没有记忆）
- FSTN-4D：检索到之前存的"用户喜欢在晚上听爵士乐工作"，回复"我记得你之前说过…"
- **一句话点评**："这就是'记忆'——而且这条记忆是**带着情绪存的**。"

## 深度展示（可选 60 秒）— 让引擎"长记忆"

如果对方感兴趣，跑：

```bash
cd ~/Desktop/fstn_enhancement/engine && python live_demo.py
```

展示 8 个完整场景，重点讲 3 个：
- **场景 4 潜意识结晶**："同样的话重复 25 次，记忆会结晶成'习惯'——之后不用提醒，它会自动避开。"
- **场景 6 情绪调制**："同样一条糖果记忆，悲伤时相关度 0.92（被压制），开心时 1.58（被加强）——情绪在决定'该想起什么'。"
- **场景 8 完整管线**："一句话进来，引擎同时做情绪检测 + 感知追踪 + 耦合 + 记忆检索 + 行为决策。"

## 常见提问应答

| 对方问 | 你的回答 |
|---|---|
| "这和向量数据库有什么区别？" | 向量库只存文本相似度；FSTN 存的是**情绪+感知+联想**的多维状态，检索时还会被当前情绪调制 |
| "有什么用？" | 陪伴型 Agent、心理咨询助手、游戏 NPC、虚拟角色——所有需要"懂人"的场景 |
| "性能如何？" | 万级记忆 0.05ms 检索；本地模型 8GB 显存可跑；也可以只挂引擎不用模型 |
| "跟大模型的关系？" | 不是替代大模型，是给大模型加"情感外设"——就像给机器人加传感器 |
| "是真的 AI 情绪吗？" | 诚实地说：是**可计算的模型**（艾克曼六维+耦合规则），不是玄学。效果可复现、可量化 |
